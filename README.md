# Multi-Threaded File Compression System

## Project Overview

This project is a **Client-Server Application** developed using **C# and .NET Windows Forms**.  
The system allows clients to send files to a server, where the files are compressed and returned back to the client.

The project demonstrates:

- TCP Socket Programming
- Multi-Threading
- File Compression
- Client-Server Communication
- GUI Development using Windows Forms
